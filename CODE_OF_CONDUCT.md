# Code of Conduct

## Our pledge

We want this project to be a welcoming, harassment-free space for everyone,
regardless of experience level, background, or identity.

## Expected behavior

- Be respectful, constructive, and patient.
- Assume good intent; give and accept feedback gracefully.
- Keep discussion focused on the code and the book.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Personal or political attacks.
- Publishing others' private information.
- Spam, self-promotion unrelated to the project, or off-topic noise.

## Enforcement

The maintainer may edit, lock, or remove comments, issues, and pull requests
that violate this Code of Conduct, and may block repeat offenders.

To report a problem, contact the maintainer via a GitHub Issue or the email
listed on the author's profile.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
