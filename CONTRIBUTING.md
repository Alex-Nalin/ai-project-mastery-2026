# Contributing

Thanks for helping improve the companion code for **AI Project Mastery 2026**! 🎉

This repo is maintained by the author. You're welcome to suggest fixes, report
broken samples, or flag outdated dependencies as the 2026 AI landscape evolves.

## How to contribute

You **cannot** push directly to `main`. The flow is:

1. **Fork** this repository (top-right "Fork" button).
2. Create a branch: `git checkout -b fix/chapter-07-typo`
3. Make your change and test it.
4. Commit with a clear message and **open a Pull Request** against `main`.
5. The maintainer reviews and merges. Please be patient and responsive to review comments.

## Ground rules

- **One change per PR.** Small, focused PRs get merged faster.
- **Keep code runnable.** If you change a sample, make sure it still runs.
- **Never commit secrets.** No API keys, tokens, or `.env` files — use `.env.example`.
- **Match the existing style** and the chapter folder structure (`chapter-NN/`).
- **Explain *why*** in the PR description, and reference the chapter/page.

## Good first contributions

- Fixing typos or broken links
- Updating a dependency or SDK call that changed
- Improving a sample's comments or README
- Reporting (via an Issue) a sample that no longer works

## Reporting problems

Open an [Issue](../../issues) with the chapter, the file, what you expected,
and the error message. That helps every reader.
